# Student Marks Dictionary (Python)

A simple Python program that stores subject-wise marks using a dictionary and calculates total and average marks.

## Features
- Accepts subject names and corresponding marks
- Stores data using a dictionary
- Displays subject-wise marks
- Calculates total and average marks

## Technologies Used
- Python 3

## How to Run
1. Download or clone the repository
2. Run the program:
   python student_marks_dictionary.py
